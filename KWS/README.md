# HELP keyword spotting from an optical microphone

Detecting and locating the spoken word "help" in a signal recovered from a laser
speckle pattern filmed at ~2940 fps.

## Results

Measured on speakers the models never saw during training.

| | value | note |
|---|---|---|
| **Detector** — AUC | **0.833** | 0.500 is a coin |
| **Detector** — balanced accuracy | **85.9%** | at threshold 0.45 |
| **Detector** — recall | 83.0% | |
| **Localizer** — top-1 within 0.5 s | **72.2%** | speakers 06, 07 |
| Localizer — fixed-time baseline | 2.2% | the control that matters |
| **End to end** | **54%** | detected *and* located correctly |

Ceilings measured on the same pipeline with real audio instead of the optical
channel:

| condition | localizer top-1 |
|---|---|
| laser, 188-688 Hz | 72% |
| microphone, 188-688 Hz | 78% |
| microphone, full band | 100% |

The task itself is fully solvable; both gaps are physical. About 6 points are
lost to the optical channel's signal quality within the usable band, and about
22 to the bandwidth the camera's 1467 Hz Nyquist limit removes.

## The one structural constraint

**Every `.py` file must sit in the same directory.** The inference scripts import
the model definitions from the training scripts:

    analyze.py -> predict.py, locate.py
    predict.py -> train_detector_mac.py -> train_help_v5_mac.py, freq_warp.py
    locate.py  -> train_help_v5_mac.py

Splitting them into subfolders breaks those imports.

## Layout

    laser_help/
    ├── README.md
    │
    ├── analyze.py                 detect, then locate if detected
    ├── predict.py                 detector only, returns a probability
    ├── locate.py                  localizer only, returns a time
    ├── evaluate_new.py            honest measurement on unseen recordings
    ├── detector_metrics.py        recall / specificity / balanced accuracy
    │
    ├── train_detector_mac.py      trains the detector
    ├── train_help_v5_mac.py       trains the localizer, holds the model defs
    ├── freq_warp.py               frequency-warp augmentation
    ├── clean_metadata.py          raw JSON -> metadata_clean.csv
    │
    ├── qc_sync.py                 mic/laser alignment and corpus health
    ├── qc_analyze.py              reads qc_report.csv in depth
    ├── band_coherence.py          measures the usable frequency band
    ├── compare_variants.py        ranks extraction variants against the mic
    ├── detection_check.py         does the localizer score carry presence?
    ├── rescore_topk.py            rescores old predictions as localization
    │
    ├── matlab/
    │   ├── Frames2Sound.m         the speckle tracker (not ours)
    │   ├── estimator_sweep.m      sweeps the tracker's parameters
    │   ├── extract_variants.m     axis and highpass variants
    │   └── region_tracking.m      3x3 tile tracking
    │
    ├── data/
    │   ├── laser/                 Laser_001.wav ... 16 kHz, 20 s
    │   ├── microphone/            microphone_001.wav ... the synchronised reference
    │   ├── Recordings_Metadata.json
    │   └── metadata_clean.csv     generated by clean_metadata.py
    │
    ├── models/
    │   ├── detector_s1/  s2/  s3/ three seeds, trained with --warp 15
    │   └── localizer/             single model, no warp
    │
    └── results/                   qc_report.csv, band_coherence.csv, ...

`models/` is `outputs/det_s1`, `det_s2`, `det_s3` and `help_v5_fixed` renamed.
Each holds seven fold subdirectories; every one of the `test_scores_*.csv` files
is needed, because they carry the calibration that turns a raw score into a
probability.

## Running it

    # one recording: decide, then locate
    python analyze.py data/laser/Laser_017.wav \
        --detector-models "models/detector_s1,models/detector_s2,models/detector_s3" \
        --localizer-models models/localizer \
        --threshold 0.45

    # a folder
    python analyze.py ./new_recordings --csv results.csv \
        --detector-models "models/detector_s1,models/detector_s2,models/detector_s3" \
        --localizer-models models/localizer --threshold 0.45

    # detector alone, as a browser page
    python predict.py --serve \
        --models "models/detector_s1,models/detector_s2,models/detector_s3"

Requires `torch numpy scipy pandas`. No GPU needed; the models are small.

## Reproducing the training

    python clean_metadata.py --json data/Recordings_Metadata.json \
        --out data/metadata_clean.csv

    # detector: 3 seeds, frequency warp on
    for s in 1 2 3; do
      python train_detector_mac.py --laser-dir data/laser \
          --meta data/metadata_clean.csv --warp 15 --seed $s \
          --output-dir models/detector_s$s
    done

    # localizer: single model, warp OFF - it measurably hurt this task
    python train_help_v5_mac.py --laser-dir data/laser --mic-dir data/microphone \
        --meta data/metadata_clean.csv --test-speaker all \
        --output-dir models/localizer

## Measuring

    # threshold table on the existing corpus
    python analyze.py data/laser --meta data/metadata_clean.csv --sweep \
        --detector-models "models/detector_s1,models/detector_s2,models/detector_s3" \
        --localizer-models models/localizer

    # recall, specificity, balanced accuracy, per speaker, with intervals
    python detector_metrics.py --laser-dir data/laser \
        --meta data/metadata_clean.csv --threshold 0.45 \
        --models "models/detector_s1,models/detector_s2,models/detector_s3"

    # localizer accuracy, each recording scored by the fold that never saw it
    python locate.py data/laser --meta data/metadata_clean.csv \
        --models models/localizer
